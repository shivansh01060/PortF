# Shivansh Narayan — Portfolio (Next.js)

1. Install Node.js 18.17+
2. `npm install`
3. `npm run dev` → http://localhost:3000
4. Deploy: push to GitHub and import into Vercel.

Edit content in `app/data.ts` (projects, tech orbs, contact) and `app/page.tsx` (hero/about text).
Portrait: `public/portrait.jpg` (cutout on black background; swap with your own square image).
